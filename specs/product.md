# 产品规格：实验室信息管理系统

| 目标场景 | 高校科研实验室 |
| 系统形态 | Web 管理系统 |
| 当前状态 | 需求已完成第一轮确认 |
| 核心 Spec | [001-lims-core/spec.md](E:/Work%20Space/SchoolWork/specs/001-lims-core/spec.md) |

## 产品目的

为高校科研实验室提供统一的信息管理能力，围绕实验任务关联样品、人员、设备、方法、实验数据、审核记录和报告，形成可追踪的实验业务闭环。

## 产品目标

- 降低实验信息分散记录造成的查询和追踪成本。
- 提高样品、任务和实验结果之间的关联性。
- 支持实验数据审核、报告生成和历史归档。
- 提供人员、设备、试剂耗材、方法和环境的基础管理能力。

## 产品边界

第一版聚焦单个高校科研实验室的 Web 管理和演示规模，不以真实仪器硬件集成、多租户、跨实验室部署或完整法规认证为交付前提。

## 利益相关者

- 系统管理员
- 实验室管理员
- 实验人员
- 项目负责人/教师
- 毕业设计指导教师和评审人员
