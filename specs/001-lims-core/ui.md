## 2. 页面清单与权限

根路径 `/` 只做会话入口解析：未登录进入 `/login`，已登录进入 `/dashboard`；不再渲染业务模块占位内容。登录成功后也统一进入 `/dashboard`。

| 页面 | 主要角色 | 关键需求 |
| --- | --- | --- |
| 登录页 | 全部 | `FR-AUTH-001` |
| 工作台 | 全部 | `FR-DASH-001～005` |
| 用户与角色 | 系统管理员 | `FR-AUTH-003～006` |
| 用户管理 | 拥有 `auth.user.manage` 的系统管理员 | `FR-AUTH-003`、`FR-AUTH-005` |
| 角色与权限管理 | 拥有 `auth.role.manage` 的系统管理员 | `FR-AUTH-004～006` |
| 基础设置 | 拥有 `settings.manage` 的管理员 | `FR-SETTING-001～003` |
| 人员列表/详情 | 系统管理员、实验室管理员 | `FR-PER-001～004` |
| 项目列表/详情 | 实验室管理员、项目负责人 | `FR-TASK-001～002` |
| 任务列表/详情 | 按任务读取权限 | `FR-TASK-001～002` |
| 任务列表/详情 | 全部按权限 | `FR-TASK-003～009` |
| 样品列表/详情 | 拥有 `sample.read` 的用户；编辑需要 `sample.manage` | `FR-SAMPLE-001～004` |
| 样品流转时间线与操作 | 查看需要 `sample.read`，登记流转需要 `sample.manage` | `FR-SAMPLE-004～006`、`AC-SAMPLE-002` |
| 方法管理 | 实验室管理员 | `FR-METHOD-001～004` |
| 数据录入 | 实验人员 | `FR-DATA-001～005` |
| 数据处理 | 实验人员、项目负责人 | `FR-DATA-007～008` |
| 结果审核 | 项目负责人/教师 | `FR-REVIEW-001～006` |
| 报告管理 | 实验室管理员、实验人员、项目负责人 | `FR-REPORT-001～006` |
| 设备管理 | 实验室管理员 | `FR-EQUIP-001～006` |
| 库存管理 | 实验室管理员、实验人员 | `FR-INVENTORY-001～006` |
| 环境管理 | 实验室管理员 | `FR-ENV-001～005` |
| 操作日志 | 系统管理员、授权管理员 | `FR-AUDIT-001～005` |

人员页面 `/personnel` 使用 `resource.read` 作为查看权限，`resource.manage` 作为编辑权限；详情页按基础档案、技能、资质、培训和任务状态分区，并对离岗、资格暂停、不可用及账户停用显示提醒。

## 3. 核心页面交互

### 3.1 任务详情页

任务详情页应以标签或分区展示：

- 基本信息：任务编号、项目、优先级、状态和计划周期。
- 样品：关联样品、样品状态和流转记录。
- 分配：实验人员、设备和资源。
- 数据：原始数据、处理数据和附件。
- 审核：审核状态、意见和历史记录。
- 报告：报告版本、发布和归档状态。
- 操作记录：任务状态和审计日志。

### 3.2 样品详情页

样品详情页应展示：

- 样品基本信息和唯一编号。
- 当前状态和存储位置。
- 所属项目和关联任务。
- 流转时间线。
- 实验数据和报告链接。
- 附件与操作历史。

### 3.3 工作台

工作台优先展示与当前角色直接相关的数据：

- 我的待办任务。
- 待审核任务。
- 样品异常或待处理提示。
- 库存和设备提醒。
- 按状态和时间的基础统计。

工作台主体导航按“管理与配置”“实验流程”“审核与报告”“资源管理”分组展示；只渲染当前用户拥有读取或管理权限的入口。已登录状态下不把 `/` 和 `/login` 作为业务导航项，顶部保留工作台身份信息和退出入口。导航布局、当前路径标识、键盘焦点和多视口规则见 [`design-dashboard-navigation.md`](design-dashboard-navigation.md)。

## 4. 页面通用规则

- 列表页统一支持分页、关键词查询、状态筛选和时间筛选。
- 新增和编辑使用统一表单校验规则。
- 删除操作默认改为停用、作废或归档。
- 状态操作必须显示确认信息和结果反馈。
- 详情页提供返回列表、编辑、状态操作和审计入口。
- 无权限按钮不显示，接口仍必须进行后端权限校验。
