## 审查结论

评估区分了当前已实现的模拟/文件边界与未来真实设备接入。推荐独立连接器或边缘网关承接设备协议、凭据、重连和缓冲，LIMS 只接收经过标准化和幂等校验的业务读数；不在 Next.js 请求处理器内直接轮询真实设备，也不把具体厂商协议误写成已支持能力。

## 风险检查

| 检查项 | 结果 |
| --- | --- |
| 设备身份、来源和采集时间可追溯 | 通过设计约束；后续连接器契约必须携带事件 ID 和来源 |
| 实验数据/环境记录绕过服务端事务 | 拒绝；继续复用模拟接口、导入接口和环境记录 RPC |
| 长连接、重试、离线缓冲和凭据进入 Web 层 | 拒绝；列为方案 B 的连接器职责 |
| 真实协议、厂商驱动或控制能力已验证 | 否；本任务无真实设备 PoC，不作正向能力声明 |
| 范围是否扩大 Spec | 否；仅登记评估结论和后续进入条件 |
